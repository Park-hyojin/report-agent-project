## 구현 범위

- **API-00~01** 서버·DB·pgvector 상태 확인 및 카테고리 조회
- **API-02~06** 보고서 등록, 상세 조회, 목록·제목 검색, 전체 수정, 삭제
- **API-07~09** 키워드·의미 유사도 검색, LLM 요약, Agent를 통한 조회·검색·요약
- **개요 색인** E5로 보고서 개요를 임베딩하고 벡터를 PostgreSQL에 저장

## 검증 결과

| 검증 항목 | Postman 확인 결과 |
|---|---|
| API-07 관련 질의 | `클래스 가중치`로 검색하니 관련 실험 보고서(1번)가 반환됐다. 키워드가 일치했고 코사인 유사도는 0.855였다. |
| API-07 무관 질의 | `화성의 낙타 전용 미용실`은 임계값 0.75에서 무관한 보고서(45번, 유사도 0.791)를 반환했다. 임계값을 0.80으로 올려 다시 검색하니 `not_found`와 `best_match: null`이 반환됐다. |
| API-08 LLM 요약 | 보고서 188번의 리비전 2를 대상으로 `gpt-6-luna`의 요약 응답과 `completed` 상태를 확인했다. |
| API-09 Agent 실행 | `get_report`로 보고서 1번을 조회하고, `find_report`로 검색 결과를 받았다. `summarize_report`는 보고서 1번의 요약을 반환했다. |

임계값 0.80에서 무관 질의의 오탐이 해소됐다. 키워드가 일치하지 않는 관련 질의도 검색되는지는, 추가 확인이 필요하다.
